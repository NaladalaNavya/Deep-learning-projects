# 🧠 Deep Learning Projects

Welcome to my **Deep Learning Projects** repository! This collection showcases a variety of projects that delve into core deep learning concepts, including image classification, natural language processing, and predictive analytics. Each project is designed to reinforce theoretical knowledge through practical implementation using Python and popular deep learning libraries.

---

## 📁 Project Overview

### 1. **CIFAR-10 Image Classification**
- **Objective:** Classify images from the CIFAR-10 dataset into 10 distinct categories.
- **Techniques:** Convolutional Neural Networks (CNNs).
- **Libraries:** `TensorFlow`, `Keras`, `NumPy`, `Matplotlib`.
- **Highlights:** Utilizes CNN architecture to achieve high accuracy in image classification tasks.

### 2. **Customer Churn Prediction**
- **Objective:** Predict customer churn based on historical data.
- **Techniques:** Deep Neural Networks (DNNs).
- **Libraries:** `TensorFlow`, `Keras`, `Pandas`, `NumPy`, `Matplotlib`.
- **Highlights:** Implements a DNN model to identify patterns leading to customer attrition.

### 3. **Handwritten Digit Recognition**
- **Objective:** Recognize handwritten digits using image data.
- **Techniques:** CNNs.
- **Libraries:** `TensorFlow`, `Keras`, `NumPy`, `Matplotlib`.
- **Highlights:** Applies CNNs to the MNIST dataset for digit classification.

### 4. **Image Classification with CNN**
- **Objective:** Classify images into predefined categories.
- **Techniques:** CNNs.
- **Libraries:** `TensorFlow`, `Keras`, `NumPy`, `Matplotlib`.
- **Highlights:** Builds a CNN model to perform image classification tasks effectively.

### 5. **Sentiment Analysis**
- **Objective:** Analyze text data to determine sentiment polarity.
- **Techniques:** Recurrent Neural Networks (RNNs), Natural Language Processing (NLP).
- **Libraries:** `TensorFlow`, `Keras`, `NLTK`, `Pandas`, `NumPy`.
- **Highlights:** Processes textual data to classify sentiments as positive or negative.

### 6. **Face Mask Detection**
- **Objective:** Detect whether individuals in images are wearing face masks.
- **Techniques:** CNNs, Object Detection.
- **Libraries:** `TensorFlow`, `Keras`, `OpenCV`, `NumPy`, `Matplotlib`.
- **Highlights:** Combines CNNs with real-time image processing to identify face mask usage.

## 🚀 Getting Started

To explore and run these projects locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/NaladalaNavya/Deep-learning-projects.git
   cd Deep-learning-projects
   ```

2. **Install dependencies:**
   *(Create a virtual environment if needed)*
   ```bash
   pip install tensorflow keras numpy pandas matplotlib nltk opencv-python
   ```

3. **Run the notebooks:**
   ```bash
   jupyter notebook
   ```
